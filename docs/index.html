Rdp Virtual Box App

Herhangi bir uygulamayı (ERP, muhasebe, raporlama, özel exe) Windows Server üzerinden RemoteApp olarak yayınlayın. İki parçalı kurulum — server tarafı + client tarafı — hem Native RDP hem de HTML5 erişim.

v1.0.0 MIT Repo Issues

Quick Start

  1. Server tarafını hazırlayın — Windows Server 2016/2019/2022, RDS rolleri, sertifika.
  2. Server Setup EXE'yi yönetici olarak çalıştırın — 7 adımlı sihirbaz.
  3. Client Setup EXE'yi son kullanıcı bilgisayarına dağıtın — 4 adımlı sihirbaz.
  4. Kullanıcı, Start Menu kısayollarından veya HTML5 web arayüzünden uygulamaları açar.

Bağlantı Stratejileri

```mermaid flowchart TD A[Kullanıcı] --> B{Hangi senaryo?} B -->|LAN / küçük ofis| C[Direct RDP - Port 3389] B -->|Dışarıdan kurumsal| D[RD Gateway - HTTPS 443] B -->|Lisans yok, HTML5| E[Apache Guacamole - HTTPS 8443] B -->|NAT arkası| F[Tailscale mesh VPN] B -->|Dışarıya port açmadan| G[Cloudflare Tunnel] B -->|Birden fazla| H[Hybrid] ```
